# First Aid AR

نموذج تجريبي تعليمي للواقع المعزز المعتمد على تتبع صورة حقيبة إسعافات أولية، باستخدام MindAR وA-Frame.

## النشر
ارفع ملفات المشروع إلى جذر مستودع GitHub، والصورة وملف التتبع إلى `assets/first-aid.png` و`assets/targets.mind`، ثم فعّل GitHub Pages من `main` و`/(root)`.

## تنبيه
المحتوى تعليمي تجريبي، وليس بديلًا عن التدريب أو الإرشادات الطبية الرسمية.
